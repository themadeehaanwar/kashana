KASHANA - how to update
1. On GitHub open family.txt and click the pencil (edit) icon.
2. Add a line under the parent. Indent 2 spaces deeper than the parent = child.
   Married couple:  Name + Spouse
   Male / female:   Name (m)   or   Name (f)     (optional)
3. Click "Commit changes". Vercel refreshes the site in about a minute.
Test locally: run  npx serve  in this folder and open the link it shows.
